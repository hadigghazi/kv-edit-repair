# Data

Put your team's data here: seed inputs, a benchmark subset, scripted
examples for evaluation, whatever your chosen baseline or extension
actually needs.

Rules, no exceptions:

- No personal data. No client data. No real users' information, ever.
- Public datasets, synthesized examples, or data your team generates
  itself.
- Everything in this folder except this file is gitignored by default,
  so committing something here takes a deliberate `git add -f`. If you do
  commit source data, keep it small and confirm again that it contains
  nothing personal.

## What is here

- `items.jsonl`: the 350 explicit-dependency items (7 cells × 50) of the main and follow-up runs.
- `items_indirect.jsonl`: the 100 paraphrased-link items (2 cells × 50) of the indirect run.

Both were generated by `python extension/kvx.py build`. They are committed (with `git add -f`) so the published
numbers can be reproduced exactly: the LLM dependency graphs stored inside them came from API calls that
cannot be repeated byte-for-byte.

**Contents:** each item has the old and new document, the edited sentence, the sentence spans and roles, the
question, the old and new answers, the erratum text, and the dependents found by the word index and the LLM
graphs. The names, aliases and codes are invented. **No personal data.**

**Licence of the background text:** the filler paragraphs are from WikiText-103 (validation split; Merity et
al., 2017), derived from Wikipedia and licensed **CC BY-SA 3.0**. The inserted benchmark sentences are ours.
